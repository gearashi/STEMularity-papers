# STEMularity-papers
Stores all of the academic preprints, papers, and journals used for the progress maps in STEMularity for reference.

## Layout
- `papers/<year>/<first author>-<year>-<title>[-arxiv<id> | -zenodo<id>].pdf`: the paper, exactly as its source served it.
- The `.json` file next to each PDF: the citation, where the file came from, its SHA-256, and its licence with the evidence for it.

## Licences
Only papers whose own licence allows sharing are kept here: CC0, public domain, CC BY, CC BY-SA, MIT, Apache-2.0, BSD,
and the non-commercial or no-derivatives Creative Commons licences (CC BY-NC, BY-NC-SA, BY-ND, BY-NC-ND).
Each paper keeps its own licence and its authors' attribution, named in its `.json` file; files under a no-derivatives
licence are stored byte for byte unchanged. Papers under any other licence, or with no licence, are never added here.
